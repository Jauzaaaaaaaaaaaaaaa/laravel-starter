# Laravel Starter

Kerangka Laravel bersih dengan halaman awal bergaya gambar teknik.

**Demo:** https://portofolio-jauza-fawaid.netlify.app/LARAVEL-STARTER/ (pratinjau statis dengan data contoh)

![Tampilan Laravel Starter](docs/tampilan.jpg)

## Menjalankan

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

## Pengujian

```bash
php artisan test
```

## Teknologi

Laravel 10
